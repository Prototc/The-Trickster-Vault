## 🗺️ 1. Guia Visual & Conceitos de APIs (Teoria)

Guia visual cobrindo a base teórica de comunicação web, verbos HTTP, rotas, ferramentas e boas práticas:

* 📄 **JSON & Estrutura de Dados:** Conceito de chave/valor, eliminação de ambiguidade e padronização de trocas de mensagens.
* 🌐 **Arquitetura API & HTTP:** A ponte de comunicação entre Cliente e Servidor e o funcionamento do protocolo HTTP.
* ⚡ **Verbos HTTP & Rotas:** Entendimento dos métodos de comunicação (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`).
* 📊 **Status Codes:** Mapeamento de respostas e códigos do servidor (`200`, `201`, `204`, `401`, `404`, `500`).
* 🛠️ **Postman & Documentação:** Testes de APIs, papel do "carteiro" e os 3 pilares de produtividade e manutenção com documentação.
